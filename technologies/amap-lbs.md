| | |
|---|---|
| **技能名称** | amap-lbs-skill |
| **状态** | ✅ 已安装 |
| **配置需求** | AMAP_WEBSERVICE_KEY（高德 Web 服务 API Key） |
| **能力** | POI 搜索、路径规划、周边搜索、热力图数据可视化 |
| **适用场景** | 酒店周边 POI、商圈分析、选址评估 |

## 项目定位

这是我已经安装到 Hermes Agent 的一个技能，不是独立的开源项目。通过调用高德地图 Web 服务 API，实现对地理位置的搜索、分析和可视化。

核心能力：
- **POI 搜索** — 搜索酒店周边的餐厅、地铁、景点、商场等设施
- **路径规划** — 计算两点间的交通距离和时间
- **热力图** — 可视化某个区域的热度分布，用于选址分析
- **旅游规划** — 结合多个 POI 做行程推荐
