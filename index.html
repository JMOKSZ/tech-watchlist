⭐ 350 1.7B 参数 酒店 AI

与 MiniCPM-V 配合可覆盖酒店视觉+听觉双维度。边缘部署潜力大。

③ amap-lbs

最现成的工具，只需配置 API Key 即可全功能调用。优先使用。

⑨ GLM-OCR

⭐ 6,787 0.9B 参数 酒店 AI

最强开源轻量 OCR。证件/发票/菜单识别直接可用。建议接入 Hermes agent。

适合做文档预处理上游。与 llm_wiki 配合使用效果最佳。

⑤ llm_wiki

⭐ 9,000 Tauri + React + Rust AI 工具

完整桌面知识库应用。知识图谱可视化、Louvain 社群检测、Deep Research、Chrome 剪藏、多格式文档支持。

六项目中最适合做 Trinity 知识后台的方案。注意 GPL v3 许可证。

🔗 GitHub|📄 分析详情 →

⑦ LightRAG

⭐ 35,600 Python AI 工具

基于知识图谱的检索增强生成系统（EMNLP 2025）。将文档提取为实体关系图，双层级检索（低级实体+高级关系），大幅提升 RAG 的覆盖度与多样性。

已关注中最重磅的项目。与 llm_wiki/Synthadoc 互补——它们做知识管理，LightRAG 做智能检索引擎。拿酒店报告实测后评估是否纳入 Trinity。

🔗 GitHub|📄 分析详情 →

⑫ turbovec

⭐ 8,181 Rust + Python MIT 向量搜索 AI

Google TurboQuant 算法的高性能向量索引 — Rust 内核 + Python 绑定。16 倍压缩（1536-dim → 384 bytes），比 FAISS 快 12-20%（ARM），在线 ingest 无需训练，SIMD NEON/AVX-512 手写内核。

直接用。 H.OS 向量存储层的零成本升级。pip install 即可替换 FAISS，M3 Max 原生加速。一人项目风险需评估。

🔗 GitHub|📄 分析详情 →

🔊 AI 语音技术

⑩ VoxCPM2

⭐ 26,679 2B 参数 30 种语言 AI

Tokenizer-free TTS 系统，直接端到端生成连续语音。30种语言（含粤语），Voice Design 可凭空造声音，可控克隆，48kHz 输出，实时流式。

当前最值得关注的 TTS 项目。Voice Design 独此一家，Apache 2.0 商用友好。等 GPU 环境部署测试。

🔗 GitHub|📄 分析详情 →

⑪ Microsoft VibeVoice-Realtime

MIT 0.5B 参数 ❌ 不支持中文 AI TTS

微软开源的流式实时 TTS 模型。Continuous Speech Tokenizer（7.5Hz）+ Next-Token Diffusion 架构，首音延迟 200-300ms（CUDA），token 级流式输出，8K 上下文窗口。

技术架构亮眼。实测 M4 上英文 RTF 1.90x（非实时），中文输出混乱——官方仅支持英文。等中文版或社区适配。
